# 生产情况 — DWD 层表

> 当前文档按照业务表结构图记录字段。数据来源、粒度和业务事件生成逻辑待后续确认。

---

## 表1：【订单生产明细业务快照表】

### 一、字段

| 字段 | 说明 |
|---|---|
| 【公司id】 | 所属公司 |
| 【客户名】 | 客户名称 |
| 【客户id】 | 客户标识 |
| 【产品id】 | 产品标识 |
| 【订单id】 | 主订单标识 |
| 【订单号】 | 主订单编号 |
| 【订单明细id】 | 订单产品明细标识 |
| 【生产状态】 | 0未处理、1不需生产、2部分生产、3全部生产 |
| 【下单数量】 | 订单明细的下单数量 |
| 【已生产数量】 | 订单明细截至当前快照的累计已生产数量 |
| 【产品类型】 | 0配方产品、1中间品、2成品、3非化妆品 |
| 【数据生成节点】 | 生成当前业务快照的业务节点 |
| 【产品名】 | 产品名称 |
| 【产品编号】 | 产品编号 |
| 【开始时间】 | 当前业务快照的开始时间 |

### 二、状态说明

【生产状态】：

- 0=未处理
- 1=不需生产
- 2=部分生产
- 3=全部生产

【产品类型】：

- 0=配方产品
- 1=中间品
- 2=成品
- 3=非化妆品
