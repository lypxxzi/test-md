# 生产情况 — ADS 层表

> 本层只使用【生产情况 — DWS 层表】作为数据来源，不再关联DWD或ODS明细表。

---

## 表1：【公司累计生产情况_天】

### 一、数据来源

【参考表】【总客户订单生产情况_天】

### 二、粒度

一个【公司id】+一个【自然日】=一行

【支持维度】【公司id】

【数据范围】取【总客户订单生产情况_天】最新【数据日期】下的全部数据，按【公司id】汇总。

### 三、字段来源

【公司id】=取【总客户订单生产情况_天】的【公司id】

【数据日期】=取【总客户订单生产情况_天】的【数据日期】，格式为“年-月-日”

【累计在生产中订单数量】=当前公司、当前数据日期下，各客户【累计在生产中订单数量】之和

【累计在生产中订单金额】=当前公司、当前数据日期下，各客户【累计在生产中订单金额】之和

【累计未生产订单数量】=当前公司、当前数据日期下，各客户【累计未生产订单数量】之和

【累计未生产订单金额】=当前公司、当前数据日期下，各客户【累计未生产订单金额】之和

### 四、生成逻辑

每天凌晨在【总客户订单生产情况_天】生成完成后，生成前一天数据。

## 表2：【业务员生产情况_天】

### 一、数据来源

【参考表】【总客户订单生产情况_天】

### 二、粒度

一个【公司id】+一个【业务员id】+一个【自然日】=一行

【支持维度】【公司id】、【业务员id】

【数据范围】取【总客户订单生产情况_天】最新【数据日期】下的全部数据，按【公司id】+【业务员id】汇总。

### 三、字段来源

【公司id】=取【总客户订单生产情况_天】的【公司id】

【业务员id】=取【总客户订单生产情况_天】的【业务员id】

【业务员名】=取【总客户订单生产情况_天】的【业务员名】

【数据日期】=取【总客户订单生产情况_天】的【数据日期】，格式为“年-月-日”

【累计在生产中订单数量】=当前业务员、当前数据日期下，各客户【累计在生产中订单数量】之和

【累计在生产中订单金额】=当前业务员、当前数据日期下，各客户【累计在生产中订单金额】之和

【累计未生产订单数量】=当前业务员、当前数据日期下，各客户【累计未生产订单数量】之和

【累计未生产订单金额】=当前业务员、当前数据日期下，各客户【累计未生产订单金额】之和

### 四、生成逻辑

每天凌晨在【总客户订单生产情况_天】生成完成后，生成前一天数据。
