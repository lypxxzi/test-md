# 回款情况 — DWD 层表

---

## 表1：【订单收款业务快照表】

### 一、数据来源

【订单收款记录表】 【订单表】

### 二、粒度

一张主订单的一次收款记录审核完成生成一行。

【业务主键】【公司id】+【订单id】+【开始时间】

【统计对象】主订单

### 三、字段

| 字段 | 说明 |
|---|---|
| 【公司id】 | 所属公司 |
| 【客户id】 | 客户标识 |
| 【客户名称】 | 客户名称 |
| 【订单id】 | 主订单标识 |
| 【订单号】 | 主订单编号 |
| 【合计金额】 | 主订单合计金额 |
| 【已收金额】 | 截至本次收款审核完成时，主订单累计已收金额 |
| 【货款状态】 | 0未收、1部分收、2已收齐 |
| 【收款日期】 | 本次审核完成的收款记录所属日期 |
| 【结账方式】 | 0未定义、1全款、2月结、3预收、4免费 |
| 【创建时间/下单时间】 | 主订单创建或下单时间 |
| 【开始时间】 | 本次收款审核完成时间 |
| 【数据生成节点】 | 生成当前业务快照的业务节点 |

### 四、事件逻辑

每次收款记录审核完成后，新增一条【订单收款业务快照表】记录，历史记录不修改。

【已收金额】保存该订单截至本次审核完成时的累计已收金额，不是本次单笔收款金额。

没有发生过审核收款的订单不进入本表。

查询某一统计时间点的订单收款情况时，每个【订单id】取该时间点之前【开始时间】最大的一条记录，作为该订单当前累计已收金额和货款状态；同一订单的多条收款快照不能相加。

### 五、能力注释

【支持】查询每张订单当前及历史时点的累计已收金额、货款状态和收款日期。

【使用边界】未进入本表的订单，在DWS关联时【已收金额】按0处理，【货款状态】按0“未收”处理。
