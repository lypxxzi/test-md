# 订单场景（统计本年度当前订单实时数据）

> 前提：本板块所有实时场景均以"本年度"为范围——统计范围 = 下单时间落在本年度的订单；跨年不累计（每年重新起算），带年度口径的 DWS/ADS 命名统一带"年度"。
>
> 总体套路：口径与单客户场景同构，粒度去掉客户id。
> - "累计×××"类：单客户日表是全历史累计、切不出年度，不能复用 → 新建公司级 DWS「公司年度订单情况_月」（场景1建，后续累计类场景在其上扩字段），ADS 每场景一张 _月 表。粒度月、数据日期 yyyy-MM，每天凌晨跑批覆盖刷新**当月行**（=截至昨天24点的年内累计），月初1号跑完上月即定格为月末快照，历史月行不再动——页面取最新月行就是实时累计值，避免每天一行的数据量
> - "按月"类（月粒度）：复用单客户各月表（月表天然按月分桶，"本年度"=取该年度各月行），公司级在 ADS 跑批时按 公司+月 跨客户求和，不新建 DWS
> - 可加指标（笔数/金额）跨客户求和；不可加指标（订单频次、各类率）先求和再算，不落 DWS

## 订单场景1：累计订单量统计

> 统计本年度当前订单实时数据：按照所有订单进行统计——订单总数、订单频次（平均下单周期）、全部发货订单数、在生产中订单数（已有生产指令的）、未排产订单数（没有生产指令的），需形成图示

粒度：一个公司 + 一个月（月末累计快照；当月行每天覆盖=截至昨天24点、本年度范围内的累计值，实时口径）

指标口径（订单主表级，数笔数，范围=下单时间落在本年度的订单）：
- 订单总数 = 本年度订单笔数【累计值】
- 订单频次（平均下单周期）=（年内最近一次下单时间 − 年内首次下单时间）÷（订单总数 −1），天；订单数≤1记0
- 全部发货订单数 = 最新行发货状态=全部发货 的笔数
- 在生产中订单数 = 未全部发货 且 任一明细最新生产状态=部分生产/全部生产 的笔数
- 未排产订单数 = 未全部发货 且 所有需生产明细最新生产状态=未处理 的笔数（不需生产的明细不参与判断）
- 三类互斥：全部发货 + 在生产中 + 未排产 ≈ 订单总数（饼图/漏斗）

### ODS 层（已有，不新增）

订单表（下单日期、发货状态）+ 4张带生产状态的订单产品明细表（配方产品/中间品/规格成品/非化妆品）

### DWD 层（复用，不新增）

- 「订单业务拉链表」——每订单取最新行：笔数、下单时间、发货状态
- 「订单生产明细业务拉链表」（单客户场景1已设计）——每明细取最新行的生产状态，判断在生产中/未排产

### DWS 层

新建「公司年度订单情况_月」（本场景先建笔数字段，场景4/6/8/10 在其上扩金额/预算/收款字段，一次跑批全算）

粒度：一行 = 一个公司 + 一个统计年度 + 一个月（每月一行=截至该月末的年内累计值；当月行每天覆盖刷新=截至昨天24点的最新累计）

| 字段 | 类型 | 说明 |
|---|---|---|
| 主键 | bigint | 自增 |
| 公司id | bigint | |
| 统计年度 | varchar(4) | yyyy |
| 订单总数 | int | 年内下单订单笔数【累计值】 |
| 首次下单时间 | bigint | 年内最早下单时间 |
| 最近下单时间 | bigint | 年内最晚下单时间 |
| 累计全部发货订单数 | int | 【累计值】 |
| 累计在生产中订单数 | int | 【累计值】 |
| 累计未排产订单数 | int | 【累计值】 |
| 数据日期 | varchar(7) | yyyy-MM |

执行时间：每天凌晨，统计截至昨天24点，覆盖刷新**当月行**（数据日期=当月 yyyy-MM）；月初1号跑完上月即定格为月末快照，历史月行不再动

执行逻辑（对每个公司）：
1、从「订单业务拉链表」取下单时间落在本年度的全部订单，每笔取最新行（剔除已删除）
2、订单总数=笔数；首次/最近下单时间=年内最早/最晚
3、最新行发货状态=全部发货 → 全部发货订单数
4、其余订单去「订单生产明细业务拉链表」查其明细（每明细取最新行）：任一明细生产状态=部分生产/全部生产 → 在生产中；需生产明细全=未处理 → 未排产
5、按 公司+年度 写入/覆盖当月行（数据日期=当月）

### ADS 层

新建「公司年度累计订单量_月」

粒度：一行 = 一个公司 + 一个统计年度 + 一个月（当月行每天覆盖，页面取最新月行=实时累计值）

| 字段 | 类型 | 说明 |
|---|---|---|
| 公司id / 公司名称 | | |
| 统计年度 | varchar(4) | yyyy |
| 订单总数 | int | DWS 当月行原值搬运 |
| 订单频次（天） | decimal(10,2) | （最近下单时间−首次下单时间）÷（订单总数−1）；订单数≤1记0 |
| 全部发货订单数 / 在生产中订单数 / 未排产订单数 | int | DWS 原值搬运 |
| 数据日期 | varchar(7) | yyyy-MM |

执行时间：每天凌晨（DWS之后），覆盖刷新当月行；用途：公司订单看板图示（饼图/漏斗）

## 订单场景2：订单按期交付统计（按月趋势）

> 所有订单进行统计：累计订单产品数（按订单产品统计）、累计已完成订单数（按完成入库时间计算）、累计按期完成订单产品数、按期完成率%、累计逾期未完成订单产品数、逾期率，需按月形成趋势图示

粒度：一个公司 + 一个自然月（本年度内逐月，每月一行=截至该月末的年内累计值，连成趋势线）；明细笔数口径。

指标口径（范围=下单时间落在本年度的订单产品明细）：
- 累计订单产品数 = 年初至该月末下单的订单产品明细行数
- 累计已完成订单数：完成入库口径数据源暂缺（同单客户按期交付），**暂按出货完成口径**（进度状态=发货完成/强制完成，完成时间取出货完成日期），待入库数据接入后切换
- 累计按期完成 = 年初至该月末完成且 出货完成日期≤约定出货日期 的明细数；按期完成率% = 累计按期完成÷累计已完成×100（分母0记0）
- 累计逾期未完成 = **该月末时点存量**：本年度内下单、截至月末未完成 且 约定出货日期<该月末 的明细数（不含往年遗留订单）；逾期率% = 累计逾期未完成÷累计订单产品数×100

### ODS 层（已有，不新增）

订单表 + 4张订单产品明细表（含 约定出货日期、出货完成日期、进度状态）

### DWD 层（复用，不新增）

- 下单线：「订单明细业务拉链表」（已有）
- 完成线：「订单出货明细业务拉链表」（单客户场景12已设计）

### DWS 层（复用，不新增）

「客户订单交付汇总_月」（单客户按期交付报表场景新建）——月表按月分桶，公司级 = 本年度各月行按 公司+月 GROUP BY（跨客户、跨产品类型求和），得各月 当月订单产品明细数/当月完成数/当月按期完成数

### ADS 层

新建「公司年度订单按期交付_月」

粒度：一行 = 一个公司 + 一个统计年度 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| 公司id / 公司名称 | | |
| 统计年度 | varchar(4) | yyyy |
| 累计订单产品数 | int | 年初至该月末各月 当月订单产品明细数 求和（跨客户） |
| 累计已完成订单产品数 | int | 同上，当月完成订单产品数 求和 |
| 累计按期完成订单产品数 | int | 同上，当月按期完成订单产品数 求和 |
| 按期完成率（%） | decimal(6,2) | 累计按期完成÷累计已完成×100（分母0记0） |
| 累计逾期未完成订单产品数 | int | 月末时点存量，从两张 DWD 直接算：业务拉链表最新有效明细中 下单时间落在本年度且≤月末、出货拉链表无完成行（或完成日期>月末）且 约定出货日期<月末 的明细数 |
| 逾期率（%） | decimal(6,2) | 累计逾期未完成÷累计订单产品数×100 |
| 数据日期 | varchar(7) | yyyy-MM |

执行时间：每天凌晨（DWS之后）——当月行每天覆盖刷新（截至昨天24点），历史月行月初定格后不再动

执行逻辑：1、从「客户订单交付汇总_月」取该公司本年度各月行按公司求和 → 三个累计数按月滚动累加；2、每月逾期存量按上表口径从 DWD 按该月末时点算；3、每月一行写入/覆盖，前端按月连趋势线

待确认：①"已完成"暂用出货完成口径代替完成入库口径；②本场景原文未写产品类型可选，按全类型合计出数。

## 订单场景6：累计订单预算利润统计

> 按照所有订单进行统计：订单总额、预算总成本、预算总利润、预算利润率(%)，需形成图示

粒度：一个公司 + 一个月（当月行每天覆盖=截至昨天24点、本年度内累计）。

指标口径（同单客户场景6）：
- 订单总额 = 年内全部订单最新行 ∑合计金额【累计值】
- 预算总成本 = 这些订单全部明细最新有效行 ∑(预算单件成本×数量)【累计值】——仅4类需生产明细有该字段（配方/中间品/规格成品/非化妆品），原料/包材/辅料算不进；空值按0
- 预算总利润 = 订单总额 − 预算总成本；预算利润率% = 预算总利润÷订单总额×100（分母0记0）

### ODS 层（已有，不新增）

订单表（合计金额）+ 4张带预算单件成本的明细表

### DWD 层（复用，不新增）

「订单业务拉链表」+「订单明细业务拉链表」（预算单件成本、数量）

### DWS 层（共用「公司年度订单情况_月」，扩2个字段）

| 新增字段 | 类型 | 说明 |
|---|---|---|
| 预算总成本 | decimal(40,20) | 年内订单全部明细最新有效行 ∑(预算单件成本×数量)【累计值】，空值按0 |
| 预算总利润 | decimal(40,20) | 订单总额 − 预算总成本【累计值】 |

执行逻辑补一步：对年内订单从「订单明细业务拉链表」取全部明细最新有效行算预算总成本，随当月行一起写入/覆盖。（利润率不落 DWS，到 ADS 算）

## 订单场景10：累计订单应收款统计

## 共用表说明：不拆表的约定

天表「客户订单情况汇总_月」/ 月表「客户新增订单量汇总_月」/ 公司级「公司年度订单情况_月」多场景共用（订单/生产/预算族=全部订单口径，收款应收族含【仅已结算订单】口径字段），约定：

1. 每个字段说明必须写清范围前缀（【仅已结算订单】= 货款状态=已收齐）
2. 不跨族运算/对账：剩余未分配的分母是已结算订单总额，不是订单总额；两个版本回款率分母不同
3. 跑批一个任务全算、整行原子写：某数据源没就绪整行不写，失败重跑整行覆盖，不能半新半旧
4. 已结算族字段命名统一带"已结算"字样
5. 加新字段前核对：粒度、时间归属轴、刷新方式三者与表一致，任一不一致必须另建表（如按期交付单独建「客户订单交付汇总_月」）

【仅已结算订单】口径字段清单：
- 天表5个：已结算订单总额、已结算订单已收款总额、剩余未分配收款总额、预收/全款单未分配总额、月结单未分配总额
- 月表5个：当月已结算订单总额、当月已结算订单已收款总额、当月剩余未分配收款总额、当月预收/全款单未分配总额、当月月结单未分配总额（范围=该月新增 且 当前货款状态=已收齐）
- 公司年度天表5个：同天表口径 + 年度范围
- ADS 派生：合计未收款总额、应收款场景回款率（分母=已结算订单总额）
