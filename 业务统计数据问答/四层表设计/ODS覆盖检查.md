# ODS 覆盖检查 — 对照《业务部门AI统计提示词》

> 核对范围口径（本次约定）：
> 1. 提示词里的 **数据分析**、**预警信息** 全部不关注 → 不核对
> 2. 其他统计中 **涉及客户的统计**（客户存量/转化/返单/地域/单客户维度等）不关注 → 不核对
> 3. **成本/利润类**（预算成本、实际成本、利润、利润率）暂不关注 → 不核对
> 4. 剩下需要分析的：订单量/订单额统计、按期交付、发货/出货统计、地域（订单侧）、TOP产品、业务员（业务绩效）维度等

现有 ODS：`ods_client`、`ods_order`、7张订单产品明细表、`ods_delivery`（发货单主表，本次新增）、`ods_delivery_detail`（发货明细表，本次新增）

---

## 一、已覆盖

| 提示词统计项 | 所需数据 | ODS 覆盖 |
|---|---|---|
| 累计/新增订单量统计（订单总数、订单频次、全部发货订单数） | 订单笔数、下单时间、发货状态 | `ods_order`（create_date、phase_status） |
| 在生产中/未排产订单数、在产情况统计 | 明细生产状态 | 4张需生产明细的 production_status（已在 ODS-3 补充字段中列明） |
| 累计/新增订单额统计 | 订单总额 | `ods_order.total_price` |
| 订单按期交付统计（按期完成率、逾期率） | 约定交期、出货完成日期、进度状态 | 7张明细（delivery_date、finish_date、phase_status） |
| 客户出货统计的出货侧 / 发货执行（数量、金额） | 每次发货的数量、时间、状态 | `ods_delivery` + `ods_delivery_detail`（本次新增，之前只有明细累计 out_quantity，无逐次发货事件） |
| TOP30 产品（订单量/金额） | 产品id/编号/名、数量、报价 | 7张明细（product_id/code/name、quantity、offer_price，已在 ODS-3 补充字段中列明） |
| 业务绩效（按业务员维度的订单统计） | 业务员id | `ods_order.business_user_id`、`ods_client.user_id/user_name`、`ods_delivery.user_id/user_name` |
| 存量订单地域统计（国内按省市） | 省/市/区、国内外 | `ods_delivery`（province/city/area、address_type）；下单侧省市在订单地址中（DWD-3 已带 province/city/area） |

## 二、缺口 / 待确认

| # | 提示词统计项 | 缺口 | 处理建议 |
|---|---|---|---|
| 1 | 「累计已完成订单数（按完成入库时间计算）」（订单按期交付/在产情况） | 无入库单相关 ODS，"完成入库时间"取不到 | 单客户场景2已定"暂不处理"；若后续要做，需增加成品入库单 ODS |
| 2 | 订单回款/应收款统计（回款率、未分配收款、预收/全款/月结） | 无收款单/结算单 ODS | 待确认是否随"成本类"一并暂不关注；若关注，需增加收款单、订单结算 ODS |
| 3 | 存量订单地域「国外按国别」 | 发货单地址只有 省/市/区 + 地址类型(国内/国外)，无"国家"字段 | 与开发确认国外地址的国别存在哪个字段（详细地址内?），或先只区分国内/国外 |
| 4 | 预备发货（delivery_type=1/2）是否计入出货统计 | 口径未定 | 与业务确认（DWD-4 已标待确认） |
| 5 | 保密客户（secret=1）/保密发货单是否计入统计 | 口径未定 | 与业务确认 |

## 三、明确不关注（本次不核对）

- 各角色下的 **数据分析** 全部小节
- 各角色下的 **预警信息** 全部小节
- 涉及客户的统计（客户基础存量/趋势/转化/返单/高订单客户/客户增降幅度/活跃客户下单等 — 已在场景1~13、单客户场景中另行设计）
- 预算成本/实际成本、预算利润/实际利润、利润率类统计（成本暂不关注）
