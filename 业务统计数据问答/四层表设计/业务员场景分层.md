# 业务员场景（业务绩效）

> 前提：业务员和客户是一对一归属关系——每个客户归属一个业务员（ods_client.user_id），业务员维度统计 = 把客户按业务员分组。订单表也自带 business_user_id，订单类指标可直接按订单表的业务员分组。
>
> 总体套路：与客户板块/订单板块同构，粒度加一层 业务员id。
> - 客户状态类：复用「客户拉链表」（dwd_client_snapshot），该表已扩 business_user_id/business_user_name 字段并监测归属变更（status 或 user_id 变则切链）——取时点行即得该时点的状态+归属业务员，归属变更前的月份自然归旧业务员
> - 订单类：复用「订单业务拉链表」等，按 business_user_id 分组
> - 累计/存量类沿用月粒度覆盖模式：数据日期 yyyy-MM，每天凌晨覆盖当月行，月初1号定格上月为月末快照，页面取最新月行=实时值

## 业务员场景1：业务客户基础存量统计

> 统计各个业务客户实时数据：客户总数、活跃客户总数、非活跃客户总数、未下单客户数（需形成存量分布图示）

粒度：ADS 一行 = 一个公司 + 一个业务员 + 一天（实时数据，每天一条=截至昨天24点的存量快照）；口径与客户板块场景1（`ads_client_base_stock_daily`）完全一致，只是按业务员分组。DWS 仍为月表（当月行每天覆盖），ADS 每天从 DWS 当月行取数——与客户板块 DWS月+ADS天 的结构对齐。

指标口径：
- 客户总数 = 该业务员名下客户数（截至昨天24点存在且未删除）
- 活跃客户总数 = 其中 状态=1活跃 的数量
- 非活跃客户总数 = 状态=2非活跃
- 未下单客户数 = 状态=0未下单
- 三分类互斥：活跃 + 非活跃 + 未下单 = 客户总数（存量分布饼图）

### ODS 层（已有，不新增）

`ods_client`（客户表）——user_id/user_name（业务员归属）、status、delete_status

### DWD 层（复用，不新增）

`dwd_client_snapshot`（客户拉链表，已扩 business_user_id/business_user_name）——取"昨天24点正在生效"的行得到每客户时点的 状态 + 归属业务员（begin_date <= 昨天24点 AND end_date > 昨天24点）；该表现在监测 status 或 user_id 任一变更即切链，所以业务员归属直接从拉链行取，归属变更前的月份归旧业务员、变更后归新业务员

### DWS 层

新建 `dws_salesperson_client_monthly`（业务员客户统计_月）——客户板块 `dws_client_monthly` 是 公司+月 粒度、没有业务员维度，不能复用，按其结构加业务员维度新建

粒度：一行 = 一个公司 + 一个业务员 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| salesperson_id | bigint | 业务员id（=ods_client.user_id） |
| salesperson_name | varchar(100) | 业务员名称 |
| total_count | int | 客户总数【存量】 |
| active_count | int | 活跃客户总数【存量】 |
| inactive_count | int | 非活跃客户总数【存量】 |
| no_order_count | int | 未下单客户数【存量】 |
| increment_count | int | 月新增客户数（创建时间落在该月）【当月增量】 |
| data_date_str | varchar(7) | 数据日期（yyyy-MM） |

执行时间：每天凌晨，统计截至昨天24点，覆盖刷新当月行；月初1号跑完上月即定格为月末快照，历史月行不再动

执行逻辑：
1、从 dwd_client_snapshot 取昨天24点正在生效的客户行（每客户一行=当前状态+归属业务员）
2、按 公司+business_user_id 分组：COUNT(*) = 客户总数；按 status 分别计数 = 活跃/非活跃/未下单；create_date 落在当月的 = 月新增客户数
3、按 公司+业务员 写入/覆盖当月行

### ADS 层

新建 `ads_salesperson_client_stock_daily`（业务员客户基础存量_天）——拷贝客户板块 ADS-1 `ads_client_base_stock_daily` 加业务员两列

粒度：一行 = 一个公司 + 一个业务员 + 一天

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| company_name | varchar(100) | 公司名称 |
| salesperson_id | bigint | 业务员id |
| salesperson_name | varchar(100) | 业务员名称 |
| total_count | int | 客户总数（DWS 当月行原值搬运） |
| active_count | int | 活跃客户总数 |
| inactive_count | int | 非活跃客户总数 |
| no_order_count | int | 未下单客户数 |
| data_date | varchar(10) | 数据日期（yyyy-MM-dd） |

执行时间：每天（DWS之后）

执行逻辑：条件：DWS 数据日期=当月，公司id=公司id——每业务员唯一一条当月行，原值搬运写当天行；用途：每业务员实时存量 + 存量分布饼图，也可全业务员横向对比条形图

## 业务员场景3：业务客户状态转化统计

> 按月统计近一年"未下单转活跃""活跃转非活跃"的转化率（需形成转化趋势图示）

粒度：一行 = 一个公司 + 一个业务员 + 一个月（近12个月趋势）；口径与客户板块场景3（`ads_client_conversion_trend_month`）完全一致，只是加业务员维度。

`ods_client`（客户表）

### DWD 层（复用，不新增）

`dwd_client_snapshot`（客户拉链表，含 business_user_id）——从拉链行的状态变化取"本月内从 status=0→1 / status=1→2"的客户数，按 business_user_id 分组

### DWS 层

新建 `dws_salesperson_client_conversion_month`（业务员客户转化_月）——客户板块 `dws_client_conversion_month` 是 公司+月 粒度、没有业务员维度，不能复用，按其结构加业务员维度新建

粒度：一行 = 一个公司 + 一个业务员 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| salesperson_id | bigint | 业务员id |
| salesperson_name | varchar(100) | 业务员名称 |
| no_order_to_active_count | int | 未下单→活跃数（本月内该业务员名下 status 0→1 的客户数） |
| no_order_to_active_rate | decimal(10,2) | 未下单→活跃转化率（= 转化数 ÷ 月初该业务员名下未下单客户数 ×100%） |
| active_to_inactive_count | int | 活跃→非活跃数（本月内 status 1→2） |
| active_to_inactive_rate | decimal(10,2) | 活跃→非活跃转化率（= 转化数 ÷ 月初该业务员名下活跃客户数 ×100%） |
| data_date_str | varchar(7) | 数据日期（yyyy-MM） |

1、从 dwd_client_snapshot 取本月内发生 status 变化的客户行（begin_date 落在本月1号~昨天24点）
2、按 business_user_id 分组：筛 旧status=0且新status=1 → 未下单转活跃数；筛 旧status=1且新status=2 → 活跃转非活跃数
3、转化率分母：月初（本月1号凌晨时间点）该业务员名下未下单/活跃客户数——从拉链表取月初生效行按 business_user_id 分组计数
4、写入/覆盖当月行

注意：客户归属变更也会切链，但 status 没变的切链行不算状态转化——只看 status 从0→1 或 1→2 的变化行

### ADS 层

## 业务员场景4：业务客户返单存量统计

> 分别按近90天、近180天、近一年，统计"未返单客户数"和"返单客户数"（需形成分周期对比图示）

粒度：ADS 一行 = 一个公司 + 一个业务员 + 一个时间类型（0近90天/1近180天/2近1年）+ 一天；口径与客户板块场景4（`ads_customer_reorder_stock_daily`）完全一致，只是按业务员分组。指标是实时存量快照（每天变化），所以 ADS 存天粒度每天一行。

指标口径：
- 返单客户数 = 该业务员名下、近N天有返单的客户数
- 未返单客户数 = 该业务员名下、下过单但近N天没有返单的客户数（不含从未下单客户）
- 返单定义：该客户第二笔及以后的订单

### DWD 层（复用，不新增）

`dwd_order_bus_snapshot`（订单业务拉链表）——每订单取最新有效行回到订单级

### DWS 层（复用，不新增）

`dws_client_repeat_order_daily`（客户返单汇总_天）——已有，粒度 公司+客户+天，含 has_repeat_90d/180d/365d 标记；**在该表上扩 business_user_id/business_user_name 两列**（DWS 跑批时从客户拉链表当前生效行取归属业务员写入），粒度不变，ADS 直接从 DWS 按 business_user_id 分组汇总，不新建 DWS

### ADS 层

| 字段 | 类型 | 说明 |

| time_type | tinyint | 时间类型（0=近90天，1=近180天，2=近1年） |

粒度：排名 = 一个公司 + 一个业务员 + 一个时间类型（近180天/近365天）+ 一个排名（1~5）+ 一天；趋势 = TOP5每客户逐月的当月返单次数。口径与客户板块场景5（`ads_high_reorder_top5_day` + `ads_customer_reorder_trend_monthly`）完全一致，只是按业务员分组——每个业务员各自的TOP5。

- 返单次数 = 该客户第二笔及以后的订单笔数（按下单时间排，首单不算）

- 趋势 = TOP5客户每自然月内新产生的返单笔数（当月增量）

## 业务员场景10：业务累计订单量统计

> 按照业务所有订单进行统计：订单总数、订单频次（平均下单周期）、全部发货订单数、在生产中订单数（已有生产指令的）、未排产订单数（没有生产指令的），需形成图示
