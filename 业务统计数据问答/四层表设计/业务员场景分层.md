# 业务员场景（业务绩效）

> 前提：业务员和客户是一对一归属关系——每个客户归属一个业务员（ods_client.user_id），业务员维度统计 = 把客户按业务员分组。订单表也自带 business_user_id，订单类指标可直接按订单表的业务员分组。
>
> 总体套路：与客户板块/订单板块同构，粒度加一层 业务员id。
> - 客户状态类：复用「客户拉链表」（dwd_client_snapshot），该表已扩 business_user_id/business_user_name 字段并监测归属变更（status 或 user_id 变则切链）——取时点行即得该时点的状态+归属业务员，归属变更前的月份自然归旧业务员
> - 订单类：复用「订单业务拉链表」等，按 business_user_id 分组
> - 累计/存量类沿用月粒度覆盖模式：数据日期 yyyy-MM，每天凌晨覆盖当月行，月初1号定格上月为月末快照，页面取最新月行=实时值

## 业务员场景1：业务客户基础存量统计

> 统计各个业务客户实时数据：客户总数、活跃客户总数、非活跃客户总数、未下单客户数（需形成存量分布图示）

粒度：ADS 一行 = 一个公司 + 一个业务员 + 一天（实时数据，每天一条=截至昨天24点的存量快照）；口径与客户板块场景1（`ads_client_base_stock_daily`）完全一致，只是按业务员分组。DWS 仍为月表（当月行每天覆盖），ADS 每天从 DWS 当月行取数——与客户板块 DWS月+ADS天 的结构对齐。

指标口径：
- 客户总数 = 该业务员名下客户数（截至昨天24点存在且未删除）
- 活跃客户总数 = 其中 状态=1活跃 的数量
- 非活跃客户总数 = 状态=2非活跃
- 未下单客户数 = 状态=0未下单
- 三分类互斥：活跃 + 非活跃 + 未下单 = 客户总数（存量分布饼图）

### ODS 层（已有，不新增）

`ods_client`（客户表）——user_id/user_name（业务员归属）、status、delete_status

### DWD 层（复用，不新增）

`dwd_client_snapshot`（客户拉链表，已扩 business_user_id/business_user_name）——取"昨天24点正在生效"的行得到每客户时点的 状态 + 归属业务员（begin_date <= 昨天24点 AND end_date > 昨天24点）；该表现在监测 status 或 user_id 任一变更即切链，所以业务员归属直接从拉链行取，归属变更前的月份归旧业务员、变更后归新业务员

### DWS 层

新建 `dws_salesperson_client_monthly`（业务员客户统计_月）——客户板块 `dws_client_monthly` 是 公司+月 粒度、没有业务员维度，不能复用，按其结构加业务员维度新建

粒度：一行 = 一个公司 + 一个业务员 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| salesperson_id | bigint | 业务员id（=ods_client.user_id） |
| salesperson_name | varchar(100) | 业务员名称 |
| total_count | int | 客户总数【存量】 |
| active_count | int | 活跃客户总数【存量】 |
| inactive_count | int | 非活跃客户总数【存量】 |
| no_order_count | int | 未下单客户数【存量】 |
| increment_count | int | 月新增客户数（创建时间落在该月）【当月增量】 |
| data_date_str | varchar(7) | 数据日期（yyyy-MM） |

执行时间：每天凌晨，统计截至昨天24点，覆盖刷新当月行；月初1号跑完上月即定格为月末快照，历史月行不再动

执行逻辑：
1、从 dwd_client_snapshot 取昨天24点正在生效的客户行（每客户一行=当前状态+归属业务员）
2、按 公司+business_user_id 分组：COUNT(*) = 客户总数；按 status 分别计数 = 活跃/非活跃/未下单；create_date 落在当月的 = 月新增客户数
3、按 公司+业务员 写入/覆盖当月行

### ADS 层

新建 `ads_salesperson_client_stock_daily`（业务员客户基础存量_天）——拷贝客户板块 ADS-1 `ads_client_base_stock_daily` 加业务员两列

粒度：一行 = 一个公司 + 一个业务员 + 一天

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| company_name | varchar(100) | 公司名称 |
| salesperson_id | bigint | 业务员id |
| salesperson_name | varchar(100) | 业务员名称 |
| total_count | int | 客户总数（DWS 当月行原值搬运） |
| active_count | int | 活跃客户总数 |
| inactive_count | int | 非活跃客户总数 |
| no_order_count | int | 未下单客户数 |
| data_date | varchar(10) | 数据日期（yyyy-MM-dd） |

执行时间：每天（DWS之后）

执行逻辑：条件：DWS 数据日期=当月，公司id=公司id——每业务员唯一一条当月行，原值搬运写当天行；用途：每业务员实时存量 + 存量分布饼图，也可全业务员横向对比条形图

## 业务员场景2：业务客户存量趋势统计

> 按月统计近一年客户总数、活跃客户总数、非活跃客户总数、未下单客户数的增长趋势（需形成趋势图示）

粒度：一行 = 一个公司 + 一个业务员 + 一个月（近12个月趋势）；口径与客户板块场景2（`ads_client_base_stock_monthly`）完全一致，只是加业务员维度。

### ODS / DWD 层（与场景1完全相同，不新增）

### DWS 层（复用场景1，不新增）

`dws_salesperson_client_monthly`（业务员客户统计_月）——月表本身就是月末存量快照（历史月已定格），近一年趋势=取近12个月行

### ADS 层

新建 `ads_salesperson_client_stock_monthly`（业务员客户基础存量_月）——拷贝客户板块 ADS-2 `ads_client_base_stock_monthly` 加业务员两列

粒度：一行 = 一个公司 + 一个业务员 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| company_name | varchar(100) | 公司名称 |
| salesperson_id | bigint | 业务员id |
| salesperson_name | varchar(100) | 业务员名称 |
| total_count | int | 客户总数 |
| active_count | int | 活跃客户总数 |
| inactive_count | int | 非活跃客户总数 |
| no_order_count | int | 未下单客户数 |
| data_date_str | varchar(7) | 数据日期（yyyy-MM） |

执行时间：每月1号（DWS之后）

执行逻辑：条件：公司id=公司id，DWS 数据日期取近12个月——每业务员12条月行原值搬运；前端每业务员四条指标线连趋势图
