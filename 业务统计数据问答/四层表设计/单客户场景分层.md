# 单客户场景（客户实时数据）

## 单客户场景1：客户累计订单量统计

> 统计客户实时数据：按照客户所有订单进行统计——订单总数、订单频次（平均下单周期）、全部发货订单数、在生产中订单数（已有生产指令的）、未排产订单数（没有生产指令的），需形成图示

粒度：一个公司 + 一个客户（全量历史累计，实时）

指标口径（全部订单主表级，数笔数）：
- 订单总数 = 该客户订单笔数【累计值】
- 订单频次（平均下单周期）=（最近一次下单时间 − 首次下单时间）÷（订单总数 − 1），单位天；订单数≤1 时记0
- 全部发货订单数 = 订单主表 phase_status=2（全部发货）的订单笔数
- 在生产中订单数 = 未全部发货 且 任一明细 production_status=2或3（部分/全部生产）的订单笔数
- 未排产订单数 = 未全部发货 且 所有需生产明细 production_status=0（未处理）的订单笔数（production_status=1不需生产的明细不参与判断）

三类互斥：全部发货 + 在生产中 + 未排产 ≈ 订单总数，可画饼图/漏斗。

### ODS 层（已有）

- `ods_order`（订单表）：create_date 下单日期、phase_status 发货状态（0未发货,1部分发货,2全部发货,3强制完成）
- 4 张带生产状态的订单产品明细表（production_status 生产状态：0未处理,1不需生产,2部分生产,3全部生产）：
  - `ods_order_recipe_product`（配方产品）
  - `ods_order_half_product`（中间品）
  - `ods_order_product_specification`（规格成品）
  - `ods_order_different_product`（非化妆品）
- 原料/包材/辅料 3 张明细无 production_status（不需生产），本场景不用

### DWD 层

- `dwd_order_bus_snapshot`（订单业务拉链表）— 已有。订单取最新行：订单总数、首次/最近下单时间、phase_status（全部发货订单数）
- `dwd_order_produce_detail_snapshot`（订单生产明细业务拉链表）—【新建】

| 字段 | 类型 | 说明 |

| monthly_unpaid_amount | decimal(40,20) | 月结单未分配总额【累计值】（场景10） |
| data_date_str | varchar | 数据日期（yyyy-MM-dd） |

执行时间：每天凌晨执行，统计截至昨天24点的累计值，每客户每天新增一行（数据日期=昨天）

数据来源：`dwd_order_bus_snapshot`（订单业务快照表）+ `dwd_order_produce_detail_snapshot`（订单生产明细业务快照表）+ `dwd_order_detail_bus_snapshot`（订单明细业务拉链表，预算成本用）+ `dwd_order_received_snapshot`（订单收款业务快照表，场景9/10）

执行逻辑（对每个客户）：
1) 从订单业务快照表取该客户全部订单，每笔订单取最新行（同一订单多行事件记录，取开始时间最大的一行，一笔订单只算一次）
2) 订单总数 = 第1步的订单笔数，累计；订单总额 = 这些订单最新行 合计金额 之和，累计
3) 首次下单时间 = 这些订单里最早的下单时间；最近下单时间 = 最晚的下单时间
4) 全部发货订单数 = 最新行发货状态=2（全部发货）的订单笔数，累计；全部发货订单额 = 这些订单的合计金额之和，累计
5) 其余未全部发货的订单，去生产明细快照表查它的明细（每条明细取最新行）：有任一明细生产状态=2部分生产或3全部生产 → 该订单算**在生产中**；需生产明细全部还是0未处理 → 该订单算**未排产**（生产状态=1不需生产的明细不参与判断），累计
6) 在生产中订单数/未排产订单数 = 第5步两类各自的订单笔数；在生产中订单额/未排产订单额 = 两类各自的合计金额之和，累计
7) 预算总成本 = 从订单明细业务拉链表取该客户全部明细的最新有效行，∑(预算单件成本×数量)，空值按0，累计；预算总利润 = 订单总额 − 预算总成本，累计
8) 订单总已收款 = 从订单收款业务快照表取该客户每笔订单的最新行（按开始时间最大），∑已收金额（没进过收款表的订单已收=0），累计；订单待收款 = 订单总额 − 订单总已收款，累计
9) 全部订单按最新行的 结账方式 分组：预收/全款单未分配总额 = 结账方式=1全款或3预收 的订单 ∑(合计金额−已收金额)，累计；月结单未分配总额 = 结账方式=2月结 的订单 ∑(合计金额−已收金额)，累计
10) 每客户每天新增一行（数据日期=昨天）

校验：全部发货 + 在生产中 + 未排产 ≈ 订单总数（三类互斥，可画饼图）

## 单客户场景2：客户订单按期交付统计

> 统计客户所有订单：累计订单产品数（按订单产品统计）、累计已完成订单数（暂不处理）、累计按期完成订单产品数、按期完成率%、累计逾期订单产品数、逾期率%

粒度：一个公司 + 一个客户（全量历史累计）；指标全部为订单产品明细级。交货日期（约定交期）= 订单明细的 delivery_date 出货日期。

指标口径：
- 累计订单产品数 = 该客户全部订单的产品明细行数【累计值】
- 累计按期完成订单产品数 = 已完成（发货完成）且 出货完成日期 ≤ 交货日期 的明细数【累计值】
- 按期完成率% = 按期完成明细数 ÷ 累计订单产品数 ×100（分母为0记0）
- 累计逾期订单产品数 = 逾期完成 + 逾期未完成【累计值】
  - 逾期完成 = 已完成 且 出货完成日期 > 交货日期
  - 逾期未完成 = 未完成 且 当前（昨天24点）> 交货日期
- 逾期率% = 逾期明细数 ÷ 累计订单产品数 ×100
- 分类关系：按期完成 / 逾期 / 未到期未完成（未到交期且未完成，不算逾期）三类互斥，占比合计100%

### ODS 层（已有）

7张订单产品明细表（delivery_date 出货日期=约定交期、finish_date 出货完成日期、phase_status 进度状态）+ `ods_order`

### DWD 层

- `dwd_order_detail_bus_snapshot`（订单明细业务拉链表）— 已有，数"累计订单产品数"用；**需补 交货日期 delivery_date 字段**（逾期未完成的明细可能从没发过货、不在出货快照表里，交期只能从这张取）
- 订单出货明细业务快照表（DWD-4）— 场景12新建那张，取每明细最新行（该订单产品id下开始时间最大）的 进度状态（1发货完成）和 出货完成日期

### DWS 层

`dws_client_order_delivery_day`（客户订单交付汇总_天）

粒度：一行 = 一个公司 + 一个客户 + 一天

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| client_id | bigint | 客户id |
| client_name | varchar(100) | 客户名称 |
| product_total_count | int | 累计订单产品数【累计值】 |
| ontime_finish_count | int | 累计按期完成订单产品数【累计值】 |
| overdue_count | int | 累计逾期订单产品数（逾期完成+逾期未完成）【累计值】 |
| data_date_str | varchar | 数据日期（yyyy-MM-dd） |

执行时间：每天凌晨执行，统计截至昨天24点的累计值，每客户每天新增一行（数据日期=昨天）

数据来源：订单明细业务拉链表 + 订单出货明细业务快照表

执行逻辑（对每个客户）：
1) 明细拉链取该客户全部订单产品明细（每明细取最新有效行）→ 累计订单产品数 = 明细行数
2) 关联出货明细快照表取每明细最新行 → 得到进度状态、出货完成日期；不在快照表里的明细 = 还没发过货（未完成）
3) 按期完成明细 = 进度状态=1发货完成 且 出货完成日期 ≤ 交货日期
4) 逾期明细 = （已完成 且 出货完成日期 > 交货日期）或（未完成 且 昨天24点 > 交货日期）
5) 每客户每天新增一行（数据日期=昨天）

### ADS 层

`ads_client_order_delivery_day`（客户订单按期交付_天）

粒度：一行 = 一个公司 + 一个客户 + 一天

## 单客户场景3：客户新增订单量按月统计

> 每个月按照客户新增订单进行统计：订单总数、订单频次（平均下单周期）、全部发货订单数、在生产中订单数、未排产订单数，需形成趋势图示

粒度：一个公司 + 一个客户 + 一个月（按下单时间归月）；指标口径同单客户场景1，但只统计"该月新增的订单"。

### ODS / DWD 层

与单客户场景1完全一样：订单业务快照表 + 订单生产明细业务快照表，不新增。

### DWS 层

`dws_client_order_produce_month`（客户新增订单量汇总_月）

粒度：一行 = 一个公司 + 一个客户 + 一个月

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| client_id | bigint | 客户id |
| client_name | varchar(100) | 客户名称 |
| order_new_count | int | 当月新增订单数【当月增量值】 |
| first_order_date | bigint | 当月首笔下单时间 |
| last_order_date | bigint | 当月末笔下单时间 |
| shipped_order_count | int | 当月新增订单中 全部发货 的笔数（当前最新状态） |
| producing_order_count | int | 当月新增订单中 在生产中 的笔数（当前最新状态） |
| unplanned_order_count | int | 当月新增订单中 未排产 的笔数（当前最新状态） |
| data_date_str | varchar | 数据日期（yyyy-MM） |

执行时间：每天凌晨跑批，覆盖更新各月行（历史月订单的状态会继续变化，如1月下的单3月才发完货，所以历史月行也随最新状态刷新）

数据来源：订单业务快照表 + 订单生产明细业务快照表

执行逻辑（对每个客户每个月）：
1) 订单业务快照表取该客户 下单时间落在该月 的订单，每笔取最新行 → 当月新增订单数、当月首/末笔下单时间
2) 状态三分类同场景1：最新行发货状态=2 → 全部发货；否则查生产明细快照表每明细最新行，任一明细生产状态=2/3 → 在生产中；需生产明细全=0未处理 → 未排产
3) 写入/覆盖该客户该月行

用途：客户详情页图示（已收款 + 待收款 = 订单总额，可画饼图/进度条 + 回款率）

## 单客户场景10：客户累计订单应收款统计

> 统计订单总额、剩余未分配收款总额、预收单/全款单未分配总额、月结单未分配总额、合计未收款总额、回款率，需形成图示

粒度：一个公司 + 一个客户（全量历史累计）。统计范围为该客户**全部订单**（不再按"已结算"圈范围）。

指标口径（全部订单主表级）：
- 订单总额 = 全部订单的合计金额之和【累计值】；合计金额 = 总报价 + 税价总计（即 ods_order 主表合计金额）——同场景4 order_total_amount
- 剩余未分配收款总额 = 全部订单 ∑(合计金额 − 已收金额)【累计值】——即场景9 的 订单待收款 unreceived_total_amount
- 预收单/全款单未分配总额 = 结账方式=全款(1)/预收(3) 的订单 ∑(合计金额 − 已收金额)【累计值】
- 月结单未分配总额 = 结账方式=月结(2) 的订单 ∑(合计金额 − 已收金额)【累计值】
- 合计未收款总额 = 预收单/全款单未分配总额 + 月结单未分配总额【累计值】
- 回款率% = 订单总已收款 ÷ 订单总额 ×100（分母为0记0）——同场景9口径

校验：剩余未分配 ≈ 合计未收款（只差结账方式=未定义/免费订单的部分）；订单总额 = 订单总已收款 + 剩余未分配。

### ODS 层（已有，不新增）

| 字段 | 类型 | 说明 |
|---|---|---|
| total_price | decimal(40,20) | 合计金额（= 总报价 + 税价总计） |
| received_price | decimal(40,20) | 已收金额（累计） |
| proceeds_mode | int | 结账方式（0未定义,1全款,2月结,3预收,4免费） |

### DWD 层（复用场景9的表，补1个字段）

### DWS 层

不新建表——在场景1的 `dws_client_order_summary_day`（客户订单情况汇总_天）上扩2个字段（订单总额场景4已扩过、总已收款/待收款场景9已扩过，剩余未分配收款总额 = 场景9的 unreceived_total_amount，直接复用）：

| 新增字段 | 类型 | 说明 |
|---|---|---|
| prepay_full_unpaid_amount | decimal(40,20) | 预收/全款单未分配总额【累计值】= 结账方式=1全款或3预收 的订单 ∑(合计金额−已收金额) |
| monthly_unpaid_amount | decimal(40,20) | 月结单未分配总额【累计值】= 结账方式=2月结 的订单 ∑(合计金额−已收金额) |

执行逻辑（每天凌晨随同一跑批，对每个客户）：
1) 从订单收款业务快照表取该客户每笔订单的最新行（按开始时间最大）；没进过收款表的订单已收=0
2) 按最新行的 结账方式 分组：结账方式=1全款或3预收 → ∑(合计金额−已收金额) = 预收/全款单未分配总额；结账方式=2月结 → ∑(合计金额−已收金额) = 月结单未分配总额
3) 随当天行一起写入（数据日期=昨天）

### ADS 层

`ads_client_order_receivable_day`（客户累计订单应收款_天）

## 单客户场景11：客户新增订单回款按月统计

> 每个月按照客户新增订单进行统计：订单总额、订单总已收款、订单待收款、回款率，需形成趋势图示

粒度：一个公司 + 一个客户 + 一个月（按下单时间归月）；只统计"该月新增的订单"，收款口径同场景9。

指标口径：
- 订单总额 = 该月新增订单的合计金额之和【当月增量值】
- 订单总已收款 = 该月新增订单的已收金额（当前累计已收）之和
- 订单待收款 = 订单总额 − 订单总已收款
- 回款率% = 订单总已收款 ÷ 订单总额 ×100（分母为0记0）

### ODS / DWD 层

与场景9完全一样，不新增：订单业务快照表 + `dwd_order_received_snapshot`（订单收款业务快照表，场景9新建）。

### DWS 层

不新建表——在场景3的 `dws_client_order_produce_month`（客户新增订单量汇总_月）上扩2个字段：

| 新增字段 | 类型 | 说明 |
|---|---|---|
| received_total_amount | decimal(40,20) | 当月新增订单总已收款 = 该月订单收款快照最新行 ∑已收金额（当前值） |
| unreceived_total_amount | decimal(40,20) | 当月新增订单待收款 = 该月订单总额 − 总已收款 |

执行逻辑：每天凌晨跑批（同场景3，覆盖刷新各月行）——对该月新增订单，从订单收款业务快照表按订单取最新行（按开始时间最大），∑已收金额 → 该月订单总已收款（没进过收款表的订单已收=0）；待收款 = 该月订单总额 − 总已收款；随该月行一起写入/覆盖（历史月订单还会继续收款，历史月行也跟着刷新）。

### ADS 层

`ads_client_order_received_month`（客户新增订单回款_月）

粒度：一行 = 一个公司 + 一个客户 + 一个月

| 字段 | 类型 | 说明 / 计算逻辑 |
|---|---|---|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| client_id | bigint | 客户id |
| client_name | varchar(100) | 客户名称 |
| order_total_amount | decimal(40,20) | 订单总额 = dws该月行原值 |
| received_total_amount | decimal(40,20) | 订单总已收款 = dws原值 |
| unreceived_total_amount | decimal(40,20) | 订单待收款 = dws原值 |
| received_rate | decimal(10,2) | 回款率% = 订单总已收款 ÷ 订单总额 ×100（分母为0记0） |
| data_date_str | varchar | 数据日期（yyyy-MM） |

执行时间：每天凌晨（DWS之后）

执行逻辑：
dws层：客户新增订单量汇总_月
　条件：公司id + 客户id，数据日期取近12个月（或统计周期内各月）→ 得到各月行

数据：每公司每客户每月一条，前端连趋势线
用途：客户详情页趋势图（各月订单额 vs 已收/待收 + 回款率走势）
