# 四层表设计规范

## 分层架构

```
ODS（原始数据层）→ DWD（明细数据层）→ DWS（汇总数据层）→ ADS（应用数据层）
```

## 规范

1. **所有接口只能访问ADS层**，前端/API不直接查ODS、DWD、DWS的表
2. **ODS层是同步覆盖的，实时更新**，从业务系统全量同步，不做任何计算
3. **DWD层是根据事件更新的，可视为实时更新**，监听ODS变化，维护拉链表/快照表
4. **ADS的跑批时间一定在DWS之后**，保证ADS取到的DWS数据是最新的
5. **DWS跑批时间：每月最后一天凌晨00:00**（月表），从DWD层聚合上月数据
6. **ADS跑批时间：在DWS完成之后执行**，从DWS层计算同环比等派生指标

## 执行顺序

```
每日凌晨：
  ① ODS ← 业务系统全量同步
  ② DWD ← 对比ODS，更新拉链表（事件驱动，可视为实时）

每月最后一天凌晨00:00：
  ③ DWS ← 从DWD聚合本月数据
  ④ ADS ← 从DWS计算同环比等，生成报表数据
```
