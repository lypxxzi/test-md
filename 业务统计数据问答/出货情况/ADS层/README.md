# 出货情况 — ADS 层表

> 本层只使用【出货情况 — DWS 层表】作为数据来源，不再关联DWD或ODS明细表。

---

## 表1：【时间维度_某客户销售品出货指标_月】

### 一、数据来源

【每月客户出货情况_月】

### 二、粒度

一个【公司id】+一个【客户id】+一个【统计类型】+一个【统计周期】=一行

【统计类型】0=月度，1=季度，2=半年，3=年度

【数据日期】格式为“年-月”；季度、半年和年度均取统计周期的最后一个月份

### 三、字段

| 字段 | 说明 |
|---|---|
| 【公司id】 | 所属公司 |
| 【客户名】 | 客户名称 |
| 【客户id】 | 客户标识 |
| 【业务员id】 | 业务员标识 |
| 【业务员名】 | 业务员名称 |
| 【数据日期】 | 统计周期末月，格式为“年-月” |
| 【统计类型】 | 0月度、1季度、2半年、3年度 |
| 【出货数量】 | 截至本周期末累计全部出货的主订单数量 |
| 【出货金额】 | 截至本周期末累计全部出货的主订单金额 |
| 【出货数量环比增减量】 | 本周期新增发货数量−上一个同类型周期新增发货数量 |
| 【出货数量环比涨跌幅】 | 出货数量环比增减量÷上一个同类型周期新增发货数量×100% |
| 【出货数量同比增减量】 | 本周期新增发货数量−上年同期新增发货数量 |
| 【出货数量同比涨跌幅】 | 出货数量同比增减量÷上年同期新增发货数量×100% |
| 【出货金额环比增减量】 | 本周期新增发货金额−上一个同类型周期新增发货金额 |
| 【出货金额环比涨跌幅】 | 出货金额环比增减量÷上一个同类型周期新增发货金额×100% |
| 【出货金额同比增减量】 | 本周期新增发货金额−上年同期新增发货金额 |
| 【出货金额同比涨跌幅】 | 出货金额同比增减量÷上年同期新增发货金额×100% |
| 【期初累计出货数量】 | 本统计周期开始前累计全部出货的主订单数量 |
| 【期初累计出货金额】 | 本统计周期开始前累计全部出货的主订单金额 |
| 【本周期新增发货数量】 | 【出货数量】−【期初累计出货数量】 |
| 【本周期新增发货金额】 | 【出货金额】−【期初累计出货金额】 |

### 四、生成/更新逻辑

1、从【每月客户出货情况_月】取得当前统计周期末月和周期开始前一个月的累计值。

2、字段对应关系：

- 【出货数量】=周期末月的【主订单全部出货数量】。
- 【出货金额】=周期末月的【主订单全部出货金额】。
- 【期初累计出货数量】=周期开始前一个月的【主订单全部出货数量】；没有历史记录时记0。
- 【期初累计出货金额】=周期开始前一个月的【主订单全部出货金额】；没有历史记录时记0。
- 【本周期新增发货数量】=【出货数量】−【期初累计出货数量】。
- 【本周期新增发货金额】=【出货金额】−【期初累计出货金额】。

3、环比取上一个连续的同类型统计周期，同比取上年相同统计周期。

4、涨跌幅的对比期值为0时记0，避免除零。

5、每天在DWS更新后覆盖当前月度、季度、半年和年度记录；统计周期结束后保留该周期最终结果。

## 表2：【总_客户发货情况_天】

### 一、数据来源

【总客户出货情况_天】

### 二、粒度

一个【公司id】+一个【客户id】+一个【自然日】=一行

### 三、字段来源

【公司id】=取【总客户出货情况_天】的【公司id】

【客户名】=取【总客户出货情况_天】的【客户名】

【客户id】=取【总客户出货情况_天】的【客户id】

【数据日期】=取【总客户出货情况_天】的【数据日期】，格式为“年-月-日”

【发货数量】=取【总客户出货情况_天】的【主订单全部出货数量】

【发货金额】=取【总客户出货情况_天】的【主订单全部出货金额】

### 四、生成逻辑

每天凌晨在【总客户出货情况_天】生成完成后，生成前一天数据。

## 表3：【公司发货情况_天】

### 一、数据来源

【总客户出货情况_天】

### 二、粒度

一个【公司id】+一个【业务员id】+一个【自然日】=一行

【支持维度】【公司id】、【业务员id】

【数据范围】取【总客户出货情况_天】最新【数据日期】下的全部数据，按【公司id】+【业务员id】汇总。

### 三、字段来源

【公司id】=取【总客户出货情况_天】的【公司id】

【业务员id】=取【总客户出货情况_天】的【业务员id】

【业务员名】=取【总客户出货情况_天】的【业务员名】

【数据日期】=取【总客户出货情况_天】的【数据日期】，格式为“年-月-日”

【发货数量】=当前业务员、当前数据日期下，各客户【主订单全部出货数量】之和

【发货金额】=当前业务员、当前数据日期下，各客户【主订单全部出货金额】之和

### 四、生成逻辑

每天凌晨在【总客户出货情况_天】生成完成后，生成前一天数据。

## 表4：【时间维度_按物料类型统计销售品出货指标_月】

### 一、数据来源

【物料类型维度_每月客户发货情况_月】

### 二、粒度

一个【公司id】+一个【客户id】+一个【产品类型】+一个【统计类型】+一个【数据日期】=一行

【支持维度】【公司id】、【客户id】、【业务员id】、【产品类型】、【统计类型】

【产品类型】0=配方产品，1=中间品，2=成品，3=非化妆品，4=原料，5=包材，6=辅料

【统计类型】0=月度，1=季度，2=半年，3=年度

【数据日期】格式为“年-月”；季度、半年和年度均取统计周期的最后一个月份

【数据范围】取【物料类型维度_每月客户发货情况_月】中，相同【公司id】+【客户id】+【产品类型】截至当前统计周期末月的全部数据。

### 三、字段

| 字段 | 说明 |
|---|---|
| 【公司id】 | 所属公司 |
| 【客户名】 | 客户名称 |
| 【客户id】 | 客户标识 |
| 【业务员id】 | 业务员标识 |
| 【业务员名】 | 业务员名称 |
| 【产品类型】 | 产品或物料类型 |
| 【数据日期】 | 统计周期末月，格式为“年-月” |
| 【统计类型】 | 0月度、1季度、2半年、3年度 |
| 【出货数量】 | 截至本周期末累计全部出货的主订单数量 |
| 【出货金额】 | 截至本周期末累计全部出货的主订单金额 |
| 【出货数量环比增减量】 | 本周期新增发货数量−上一个同类型周期新增发货数量 |
| 【出货数量环比涨跌幅】 | 出货数量环比增减量÷上一个同类型周期新增发货数量×100% |
| 【出货数量同比增减量】 | 本周期新增发货数量−上年同期新增发货数量 |
| 【出货数量同比涨跌幅】 | 出货数量同比增减量÷上年同期新增发货数量×100% |
| 【出货金额环比增减量】 | 本周期新增发货金额−上一个同类型周期新增发货金额 |
| 【出货金额环比涨跌幅】 | 出货金额环比增减量÷上一个同类型周期新增发货金额×100% |
| 【出货金额同比增减量】 | 本周期新增发货金额−上年同期新增发货金额 |
| 【出货金额同比涨跌幅】 | 出货金额同比增减量÷上年同期新增发货金额×100% |
| 【期初累计出货数量】 | 本统计周期开始前累计全部出货的主订单数量 |
| 【期初累计出货金额】 | 本统计周期开始前累计全部出货的主订单金额 |
| 【本周期新增发货数量】 | 当前统计周期新增全部出货的主订单数量 |
| 【本周期新增发货金额】 | 当前统计周期新增全部出货的主订单金额 |

### 四、生成/更新逻辑

1、按照【公司id】+【客户id】+【产品类型】分别计算，不同客户、不同产品类型的数据不合并。

2、字段对应关系：

- 【出货数量】=截至当前统计周期末月，各月【当月主订单全部出货数量】之和。
- 【出货金额】=截至当前统计周期末月，各月【当月主订单全部出货金额】之和。
- 【期初累计出货数量】=当前统计周期开始月份以前，各月【当月主订单全部出货数量】之和。
- 【期初累计出货金额】=当前统计周期开始月份以前，各月【当月主订单全部出货金额】之和。
- 【本周期新增发货数量】=当前统计周期内，各月【当月主订单全部出货数量】之和。
- 【本周期新增发货金额】=当前统计周期内，各月【当月主订单全部出货金额】之和。

3、环比取上一个连续的同类型统计周期，同比取上年相同统计周期。

4、涨跌幅的对比期值为0时记0，避免除零。

5、每天在DWS更新后覆盖当前月度、季度、半年和年度记录；统计周期结束后保留该周期最终结果。

### 五、能力注释

【支持】选择单个【产品类型】查询客户发货数量、金额及同比环比。

【使用边界】同一主订单包含多个【产品类型】时，会分别计入多个类型；不同产品类型的【出货数量】和【出货金额】不能直接相加。查询全部产品类型合计时，应使用【时间维度_某客户销售品出货指标_月】。
