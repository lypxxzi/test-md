# 产线包装产能统计 — 场景与ADS层设计

> 范围：仅"产线包装产能统计，含单品组品产能"。产线：护肤线/蜡基线/粉单元线。
> 口径说明：总产能、单品产能、组品产能三个指标独立取数，单品+组品不要求等于总产能。
> 时间口径：不支持自定义区间由用户直接传表达式，"今天/近15天/近12周/近一年"等由问答层解析为开始/结束日期后传入接口。

## 二、ADS层表设计（共6张）

> 跑批时间均在DWS之后执行，所有接口只访问ADS层。

### ADS-1：`ads_line_packaging_capacity_daily`（产线包装产能_天）

**服务接口：** 接口2（按日汇总）、接口3（按周汇总，接口按自然周求和）

**粒度：一个公司 + 一条产线 + 一天**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| day_total_qty | int | 当日包装总产能（件） |
| day_single_qty | int | 当日单品产能（件） |
| day_combo_qty | int | 当日组品产能（件） |

**执行时间：** 每天

### ADS-3：`ads_line_packaging_cum_daily`（产线包装累计产能_天）

**服务接口：** 接口1（累计/占比统计）

**粒度：一个公司 + 一条产线 + 一天**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| cum_total_qty | bigint | 截至当日历史累计总产能（件） |
| cum_single_qty | bigint | 截至当日历史累计单品产能（件） |
| cum_combo_qty | bigint | 截至当日历史累计组品产能（件） |
| data_date | varchar | 数据日期（yyyy-MM-dd） |

**执行时间：** 每天

**接口取数方式（以"今天7月17日，近15天累计"为例）：**
1. 近15天 = 7月3日～7月17日（由问答层换算为开始/结束日期）
2. 每产线取两行：7月17日的 cum_* 减 7月2日（开始日前一天）的 cum_*，差值即区间累计
3. 占比 = 区间单品（组品）累计 ÷ 区间总累计
4. 截至某日的历史累计 = 该日单行的 cum_*（开始日期不传时直接取结束日单行）
5. 日均/周均/月均产能由按日/按周/按月接口各自返回（区间值之和÷期数），不走本表
