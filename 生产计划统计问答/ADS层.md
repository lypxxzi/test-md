# 产线包装产能统计 — 场景与ADS层设计

> 范围：仅"产线包装产能统计，含单品组品产能"。产线：护肤线/蜡基线/粉单元线。
> 口径说明：总产能、单品产能、组品产能三个指标独立取数，单品+组品不要求等于总产能。
> 时间口径：不支持自定义区间由用户直接传表达式，"今天/近15天/近12周/近一年"等由问答层解析为开始/结束日期后传入接口。

## 二、ADS层表设计（共6张）

> 跑批时间均在DWS之后执行，所有接口只访问ADS层。

### ADS-1：`ads_line_packaging_capacity_daily`（产线包装产能_天）

**服务接口：** 接口2（趋势-日/周粒度）、接口1（历史最高日产能）

**粒度：一个公司 + 一条产线 + 一天**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| day_total_qty | int | 当日包装总产能（件） |
| day_single_qty | int | 当日单品产能（件） |
| day_combo_qty | int | 当日组品产能（件） |
| hist_max_qty | int | 截至当日历史最高日产能（件/天），跑批时与前一日比较维护 |
| data_date | varchar | 数据日期（yyyy-MM-dd） |

**执行时间：** 每天

### ADS-2：`ads_line_packaging_capacity_monthly`（产线包装产能_月）

**服务接口：** 接口2（趋势-月粒度，近一年/近三年）

**粒度：一个公司 + 一条产线 + 一个月**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| month_total_qty | int | 当月包装总产能（件） |
| month_single_qty | int | 当月单品产能（件） |
| month_combo_qty | int | 当月组品产能（件） |
| data_date_str | varchar | 数据月份（yyyy-MM） |

**执行时间：** 每月1号

### ADS-3：`ads_line_packaging_cum_daily`（产线包装累计产能_天）

**服务接口：** 接口1（累计/平均/占比统计）

**粒度：一个公司 + 一条产线 + 一天**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| cum_total_qty | bigint | 截至当日历史累计总产能（件） |
| cum_single_qty | bigint | 截至当日历史累计单品产能（件） |
| cum_combo_qty | bigint | 截至当日历史累计组品产能（件） |
| data_date | varchar | 数据日期（yyyy-MM-dd） |

**执行时间：** 每天

**接口取数方式（以"今天7月17日，近15天累计"为例）：**
1. 近15天 = 7月3日～7月17日（由问答层换算为开始/结束日期）
2. 每产线取两行：7月17日的 cum_* 减 7月2日（开始日前一天）的 cum_*，差值即区间累计
3. 平均产能 = 区间累计 ÷ 期数（日均÷天数、周均÷周数、月均÷月数）
4. 占比 = 区间单品（组品）累计 ÷ 区间总累计
5. 历史最高日产能 = ADS-1最新一行的 hist_max_qty
6. 截至某日的历史累计 = 该日单行的 cum_*

### ADS-4：`ads_line_packaging_ratio_monthly`（产线包装产能同环比_月）

**服务接口：** 接口3（统计类型=月度）

**粒度：一个公司 + 一条产线 + 一个月**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| total_qty | int | 本月总产能（件） |
| single_qty | int | 本月单品产能（件） |
| combo_qty | int | 本月组品产能（件） |
| total_yoy_rate | decimal | 总产能同比增减幅度（%） |
| total_mom_rate | decimal | 总产能环比增减幅度（%） |
| single_yoy_rate | decimal | 单品产能同比增减幅度（%） |
| single_mom_rate | decimal | 单品产能环比增减幅度（%） |
| combo_yoy_rate | decimal | 组品产能同比增减幅度（%） |
| combo_mom_rate | decimal | 组品产能环比增减幅度（%） |
| hist_max_qty | int | 历史最高月产能（件） |
| hist_max_rate | decimal | 历史最高达成率（%）＝本月总产能/历史最高月产能 |
| data_date_str | varchar | 统计月（yyyy-MM） |

**执行时间：** 每月1号

**执行逻辑：** 同比=对比去年同月，环比=对比上月；历史最高=全历史月产能max

### ADS-5：`ads_line_packaging_ratio_quarterly`（产线包装产能同环比_季）

**服务接口：** 接口3（统计类型=季度）

**粒度：一个公司 + 一条产线 + 一个季度**

字段同 ADS-4，差异：统计期为 `data_date_str`（yyyy-Qn）；hist_max_qty=历史最高季产能；同比=对比去年同季，环比=对比上一季度

**执行时间：** 每季度首日

### ADS-6：`ads_line_packaging_ratio_yearly`（产线包装产能同环比_年）

**服务接口：** 接口3（统计类型=年度）

**粒度：一个公司 + 一条产线 + 一年**

字段同 ADS-4，差异：统计期为 `data_date_str`（yyyy）；hist_max_qty=历史最高年产能；同比与环比相同（均对比上一年）

**执行时间：** 每年1月1号

| 表 | 粒度 | 说明 |

| `dws_line_packaging_capacity_daily`（产线包装产能汇总_天） | 公司+产线+天 | 由DWD包装生产明细按天聚合，供ADS-1/ADS-3 |
