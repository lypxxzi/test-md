# 产线包装产能统计 — 场景与ADS层设计

> 范围：仅"产线包装产能统计，含单品组品产能"。产线：护肤线/蜡基线/粉单元线。
> 口径说明：总产能、单品产能、组品产能三个指标独立取数，单品+组品不要求等于总产能。
> 时间口径：不支持自定义区间由用户直接传表达式，"今天/近15天/近12周/近一年"等由问答层解析为开始/结束日期后传入接口。

## 二、ADS层表设计（共6张）

> 跑批均为T+1（每天/每期首日生成上一期数据），在DWS之后执行，所有接口只访问ADS层。
> 数据边界说明：如上线时不回刷历史数据，"历史累计/历史最高/同比环比"均为上线以来口径，回答时需说明可统计的起始时间；无对比期数据时同环比字段为空。

### ADS-1：`ads_line_packaging_capacity_daily`（产线包装产能_天）

**一、数据来源：** 产线包装产能汇总_天（DWS）

**二、粒度**

一个【公司id】+ 一条【产线id】+ 一个【自然日】= 一行

【时间口径】自然日

【支持维度】【公司id】、【产线id】

【支持指标】【当日包装总产能（件）】、【当日单品产能（件）】、【当日组品产能（件）】、【截止当日历史最高日产能（件/天）】

**三、表说明**

每天保存每条产线当天包装的总产能、单品产能、组品产能，以及截至当天的历史最高日产能

**四、生成逻辑**

1、每天生成昨天的数据

1. 条件：公司id=公司id，数据日期=昨天，每条产线取3行（总产能/单品/组品各一行），得到当日总产能、当日单品产能、当日组品产能
2. 取本表前天该产线的一行，拿到"截止前天的历史最高日产能"
3. 截止当日历史最高日产能 = max（前一天的历史最高，当日总产能）；首次跑批无前值时 = 当日总产能
4. 输出：每天每公司每产线1条

**服务接口：** 按日汇总、按周汇总（接口按自然周求和）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| day_total_qty | int | 当日包装总产能（件） |
| day_single_qty | int | 当日单品产能（件） |
| day_combo_qty | int | 当日组品产能（件） |
| hist_max_qty | int | 截止当日历史最高日产能（件/天） |
| data_date | varchar | 数据日期（yyyy-MM-dd） |

### ADS-2：`ads_line_packaging_capacity_monthly`（产线包装产能_月）

**一、数据来源：** 产线包装产能汇总_月（DWS）

**二、粒度**

一个【公司id】+ 一条【产线id】+ 一个【自然月】= 一行

【时间口径】自然月

【支持维度】【公司id】、【产线id】

【支持指标】【当月包装总产能（件）】、【当月单品产能（件）】、【当月组品产能（件）】

**三、表说明**

每月保存每条产线当月包装的总产能、单品产能、组品产能

**四、生成逻辑**

1、每月1号：修正上月的数据

1. 条件：公司id=公司id，数据月份=上月，每条产线取3行（总产能/单品/组品各一行），得到上月完整的总/单品/组品产能
2. 用完整月数据覆盖更新本表上月那一行（终版定稿）

2、每月2号：生成本月的数据

1. 条件：公司id=公司id，取本月1号的日生产数量（总/单品/组品）
2. 新增本月一行，当月值=截至昨天的本月生产数量

3、每月3号之后：每天更新本月的数据

1. 条件：公司id=公司id，取本月1号至昨天的日生产数量按类型求和
2. 用求和结果覆盖更新本表本月那一行（当月值随每天跑批滚动增加）

**服务接口：** 按月汇总（月表始终有当月行，数据截至昨天，接口直接读表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| month_total_qty | int | 当月包装总产能（件） |
| month_single_qty | int | 当月单品产能（件） |
| month_combo_qty | int | 当月组品产能（件） |
| data_date_str | varchar | 数据月份（yyyy-MM） |

### ADS-3：`ads_line_packaging_cum_daily`（产线包装累计产能_天）

**一、数据来源：** 产线包装产能汇总_天（DWS）

**二、粒度**

一个【公司id】+ 一条【产线id】+ 一个【自然日】= 一行

【时间口径】日累计快照

【支持维度】【公司id】、【产线id】

【支持指标】【截至当日历史累计总产能（件）】、【截至当日历史累计单品产能（件）】、【截至当日历史累计组品产能（件）】

**三、表说明**

每天保存每条产线截至当天的历史累计总产能、累计单品产能、累计组品产能

**四、生成逻辑**

1、每天生成昨天的数据

1. 条件：公司id=公司id，数据日期=昨天，每条产线取3行（总产能/单品/组品各一行），得到当日总产能、当日单品产能、当日组品产能
2. 取本表前天该产线的一行，拿到"截止前天的历史累计总产能、累计单品产能、累计组品产能"
3. 今天的累计 = 前一天的累计 ＋ 当日值（总、单品、组品各自相加）；首次跑批无前值时累计 = 当日值
4. 输出：每天每公司每产线1条

**接口取数：** 任意区间累计 = 结束日累计 − 开始日前一天累计（两行相减）；截至某日累计 = 该日单行；占比 = 单品（组品）区间累计 ÷ 总区间累计

**服务接口：** 累计统计

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| cum_total_qty | bigint | 截至当日历史累计总产能（件） |
| cum_single_qty | bigint | 截至当日历史累计单品产能（件） |
| cum_combo_qty | bigint | 截至当日历史累计组品产能（件） |
| data_date | varchar | 数据日期（yyyy-MM-dd） |

### ADS-4：`ads_line_packaging_ratio_monthly`（产线包装产能同环比_月）

**一、数据来源：** 产线包装产能汇总_月（DWS）

**二、粒度**

一个【公司id】+ 一条【产线id】+ 一个【自然月】= 一行

【时间口径】自然月

【支持维度】【公司id】、【产线id】

【支持指标】【本月总/单品/组品产能（件）】、【总/单品/组品产能同比增减数（件）与同比增降幅度（%）】、【总/单品/组品产能环比增减数（件）与环比增降幅度（%）】、【历史最高月产能（件）】、【历史最高达成率（%）】

**三、表说明**

每月保存每条产线当月总/单品/组品产能，及各自同比环比的增减数和增降幅度、历史最高月产能与达成率

**四、生成逻辑**

1、每月1号生成上个月的数据

1. 条件：公司id=公司id，数据月份=上月，每条产线取3行行转列，得到本月总产能、单品产能、组品产能
2. 取去年同月的月数据（同比对比值）、上上月的月数据（环比对比值）
3. 同比增减数 = 本月 − 去年同月；同比增降幅度 = 增减数 ÷ 去年同月 × 100%（总、单品、组品各自计算）；无去年同月数据时字段为空
4. 环比增减数 = 本月 − 上上月；环比增降幅度 = 增减数 ÷ 上上月 × 100%；无上一期数据时字段为空
5. 历史最高月产能 = max（本表历史各月总产能，本月总产能）；历史最高达成率 = 本月总产能 ÷ 历史最高月产能 × 100%
6. 输出：每月每公司每产线1条

**服务接口：** 周期同环比统计（统计类型=月度）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| company_id | bigint | 公司id |
| line_id | bigint | 产线id |
| line_name | varchar | 产线名称 |
| total_qty | int | 本月总产能（件） |
| single_qty | int | 本月单品产能（件） |
| combo_qty | int | 本月组品产能（件） |
| total_yoy_diff | int | 总产能同比增减数（件，本月−去年同月） |
| total_yoy_rate | decimal | 总产能同比增降幅度（%） |
| total_mom_diff | int | 总产能环比增减数（件，本月−上月） |
| total_mom_rate | decimal | 总产能环比增降幅度（%） |
| single_yoy_diff | int | 单品产能同比增减数（件） |

### ADS-5：`ads_line_packaging_ratio_quarterly`（产线包装产能同环比_季）

**一、数据来源：** 产线包装产能汇总_月（DWS）

**二、粒度**

一个【公司id】+ 一条【产线id】+ 一个【自然季度】= 一行

【时间口径】自然季度

【支持维度】【公司id】、【产线id】

【支持指标】【本季度总/单品/组品产能（件）】、【总/单品/组品产能同比增减数（件）与同比增降幅度（%）】、【总/单品/组品产能环比增减数（件）与环比增降幅度（%）】、【历史最高季度产能（件）】、【历史最高达成率（%）】

**三、表说明**

每季度保存每条产线本季度总/单品/组品产能，及各自同比环比的增减数和增降幅度、历史最高季度产能与达成率

**四、生成逻辑**

1、每季度首日生成上一季度的数据

1. 条件：公司id=公司id，数据月份=上一季度3个月，每条产线按类型行转列后3个月求和，得到本季度总产能、单品产能、组品产能
2. 取去年同季度数据（同比对比值）、上上季度数据（环比对比值）
3. 同比增减数 = 本季度 − 去年同季度；同比增降幅度 = 增减数 ÷ 去年同季度 × 100%；无数据时字段为空
4. 环比增减数 = 本季度 − 上一季度；环比增降幅度 = 增减数 ÷ 上一季度 × 100%；无数据时字段为空
5. 历史最高季度产能 = max（本表历史各季度总产能，本季度总产能）；历史最高达成率 = 本季度总产能 ÷ 历史最高季度产能 × 100%
6. 输出：每季度每公司每产线1条

## 三、DWS层依赖（共2张，按类型行存）

### DWS-1：`dws_line_packaging_capacity_daily`（产线包装产能汇总_天）
