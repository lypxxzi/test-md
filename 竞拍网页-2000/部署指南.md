# 竞拍系统部署指南

## 一、环境准备

### 必需软件
- JDK 17
- Maven 3.6+
- Node.js 16+
- MySQL 8.0
- Redis

## 二、数据库初始化

### 1. 连接MySQL

```bash
mysql -h 115.190.209.228 -P 3306 -u root -p
# 输入密码: lwc520..
```

### 2. 执行初始化脚本

```bash
mysql -h 115.190.209.228 -P 3306 -u root -plwc520.. < database/init.sql
```

或在MySQL客户端中执行 `database/init.sql` 文件。

## 三、后端部署

### 1. 进入后端目录

```bash
cd auction-backend
```

### 2. 编译打包

```bash
mvn clean package
```

### 3. 启动服务

```bash
java -jar target/auction-backend-1.0.0.jar
```

或使用Maven直接运行：

```bash
mvn spring-boot:run
```

### 4. 验证启动

访问 http://localhost:8080/doc.html 查看接口文档

## 四、用户前台部署

### 1. 进入前台目录

```bash
cd auction-frontend
```

### 2. 安装依赖

```bash
npm install
```

### 3. 开发模式启动

```bash
npm run dev
```

访问 http://localhost:3000

### 4. 生产环境构建

```bash
npm run build
```

构建产物在 `dist` 目录，可部署到Nginx。

## 五、管理后台部署

### 1. 进入后台目录

```bash
cd auction-admin
```

### 2. 安装依赖

```bash
npm install
```

### 3. 开发模式启动

```bash

```

### 4. 生产环境构建


## 六、Nginx配置示例

```nginx
server {
    listen 80;
    server_name auction.example.com;

    # 用户前台
    location / {
        root /path/to/auction-frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 管理后台
    location /admin {
        root /path/to/auction-admin/dist;
        try_files $uri $uri/ /admin/index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 九、常见问题

### 1. 后端启动失败
- 检查JDK版本是否为17
- 检查MySQL和Redis连接是否正常
- 查看日志文件定位错误

### 2. 前端启动失败
- 检查Node.js版本
- 删除 node_modules 重新安装依赖
- 检查后端API是否正常运行

### 3. 无法连接数据库
- 确认MySQL服务正在运行
- 检查数据库地址、端口、用户名、密码是否正确
- 检查防火墙设置

### 4. Redis连接失败
- 确认Redis服务正在运行
- 检查Redis地址、端口、密码是否正确
