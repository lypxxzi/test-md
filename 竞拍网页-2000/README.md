# 竞拍系统项目

## 项目简介

基于 **Vue3 + Spring Boot + MySQL + Redis** 的在线竞拍系统，包含用户竞拍前台和管理后台。

- **竞拍日期**：2026年1月26日 - 1月30日
- **竞拍时间**：每日 09:30 - 18:00
- **竞拍规则**：起拍价1000🍎，每次加价100🍎，价高者得

## 数据库表说明

### 1. auction_item（竞拍商品表）
存储竞拍活动日期、价格、时间段等信息

### 2. user（用户表）
存储参与竞拍的用户信息（姓名、代理人代码、营业区）

### 3. bid_record（竞拍记录表）
记录每次竞拍的详细信息

### 4. admin（管理员表）
管理后台登录账号

### 5. system_config（系统配置表）
系统参数配置（访问密码、起拍价等）

## 注意事项

1. **价格单位**：系统中所有价格均使用 🍎 符号表示
2. **并发控制**：使用Redis分布式锁防止并发竞拍问题
3. **时间控制**：非竞拍时间段（09:30-18:00之外）不允许竞拍
4. **数据安全**：管理员密码使用BCrypt加密，Token存储在Redis
5. **实时更新**：前端需定时轮询或使用WebSocket实现实时数据更新
